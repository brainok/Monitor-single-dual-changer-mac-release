# Monitor Toggle v1.0.1

- 새 앱 아이콘과 Git 태그 버전이 표시되는 About 화면.
- Brainok 라이선스 입력, Keychain 저장 및 오프라인 활성화 복원.
- 공용 호환 코드 지원과 한글/영문 입력 상태의 Command-V 붙여넣기 수정.
- 흰 배경의 드래그 설치 DMG. 앱과 Applications 아이콘의 y 좌표는 모두 275.

대상: macOS 14 이상 / Apple Silicon (arm64).
파일명: `MonitorToggle.dmg`.

앱과 DMG는 Developer ID 서명 및 Apple 공증 후 배포합니다. 실제 라이선스 서버 등록은 릴리스 검증에서 수행하지 않았습니다.
