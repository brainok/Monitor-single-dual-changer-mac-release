# Monitor Toggle v1.1.1

- 설정 화면에서 Brainok 라이선스 입력 및 활성화 상태 확인.
- 로그인 시 자동 실행 선택.
- 전역 단축키 Control–Shift–1로 싱글, Control–Shift–2로 듀얼 화면 전환. 설정에서 단축키 사용 선택.
- 앱 제목 아래 v1.1.1을 표시하는 흰 배경 DMG. 128포인트 아이콘과 중앙 화살표, 스크롤바 없는 설치 화면.

대상: macOS 14 이상 / Apple Silicon (arm64).
화면 전환에는 `brew install jakehilborn/jakehilborn/displayplacer`로 설치하는 displayplacer가 필요합니다.
파일명: `MonitorToggle.dmg`.

소스 v1.1.1 태그 기준으로 빌드했습니다. 앱과 DMG 모두 Developer ID 서명 및 Apple 공증을 완료했습니다. 실제 라이선스 서버 등록은 릴리스 검증에서 수행하지 않았습니다.
